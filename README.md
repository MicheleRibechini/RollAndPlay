# Roll&Play

Codice di build e siti dei manuali dei giochi Roll&Play. I testi dei manuali non stanno qui: questo repo contiene solo la build e il suo output.

- `build/`: script, testi dell'interfaccia, CSS e JavaScript che generano il sito. Istruzioni in `build/README.md`.
- `docs/`: output pubblicato con GitHub Pages. `docs/index.html` è la home di Roll&Play, ogni setting ha la sua cartella.
