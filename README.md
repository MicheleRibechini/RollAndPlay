# Roll&Play

Codice di build e siti dei manuali dei giochi Roll&Play. I testi dei manuali non stanno qui: questo repo contiene solo la build e il suo output.

- `build/`: script e template che generano i siti.
- `docs/`: output pubblicato con GitHub Pages. `docs/index.html` è la pagina di scelta del setting, ogni setting ha la sua cartella.
